# PennyPost OpenAPI specification

The canonical API description for [PennyPost](https://pennypost.io), the
affordable email API. Every official SDK is generated from this file.

- Spec: [openapi.json](openapi.json) (sha `13bb405e5ef5`)
- Docs: https://pennypost.io/docs
- Machine-readable docs: https://pennypost.io/docs.md and https://pennypost.io/llms.txt
- SDKs: [node](https://github.com/pennypost-io/pennypost-node), [python](https://github.com/pennypost-io/pennypost-python), [go](https://github.com/pennypost-io/pennypost-go), [php](https://github.com/pennypost-io/pennypost-php), [rust](https://github.com/pennypost-io/pennypost-rust)
